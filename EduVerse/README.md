# StudentHub

StudentHub is a student management website developed using HTML, CSS, JavaScript, PHP, and MySQL.

## Features
- User registration and secure login
- Session management and logout
- Admin dashboard with statistics
- Student management (CRUD operations)
- Event management with poster uploads
- Events API using PHP and Fetch API
- MySQL database integration

## Technologies Used
- HTML and CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Local Setup
1. Install and start Apache and MySQL using XAMPP.
2. Copy the project folder into `htdocs`.
3. Import the StudentHub SQL database using phpMyAdmin.
4. Configure the database connection in `db.php`.
5. Open the project through your local Apache server.
